# Hands-on Workshop: Building Resilient Microservices with Java

This intensive hands-on workshop provides participants with practical experience building production-ready microservices using modern Java frameworks and tools. Through guided exercises, attendees will implement a complete microservices ecosystem including service discovery with Consul, API gateway configuration with Spring Cloud Gateway, and distributed tracing with Jaeger. The workshop covers essential patterns for handling distributed transactions, implementing circuit breakers with Resilience4j, and managing configuration across multiple services. Participants will work with containerization using Docker, orchestration with Kubernetes, and monitoring solutions including Prometheus and Grafana. By the end of the session, attendees will have built a fully functional microservices application with proper error handling, logging, and observability features that can be deployed to cloud platforms.
