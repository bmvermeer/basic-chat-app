# basic-chat-app

This is a demo application for a talk by Brian Vermeer called **"Understanding Prompt Injection Techniques"**.

## Run

1. Add your API key as an environment variable:

```sh
export OPEN_API_KEY=your_api_key_here
```

2. Start the application:

```sh
./mvnw quarkus:dev
```

3. Open the app in your browser:

<http://localhost:8080>
